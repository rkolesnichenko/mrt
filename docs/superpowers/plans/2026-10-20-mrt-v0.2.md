# mrt v0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `mrt` hand a reconciliation library everything it needs to keep a table of three full RIBs plus updates in about 8 GB: peer-state events, route age, shared paths that hold no record bytes, exported diagnostic codes and typed extended communities.

**Architecture:** `bgp` gains `Path.Clone`, an `Interner` (whole-path sharing for RIB blocks, component sharing for the rest), typed `ExtCommunity` accessors and diagnostic-code constants; ruling R20 changes so a RIB entry's full-form MP_REACH NLRI is not kept. `mrt` gains `RoutesWith`/`RoutesOptions` (peer-state events, an interner) and `Route.Originated`. A throwaway command measures sharing on the three real RIBs before the interner's API is built.

**Tech Stack:** Go 1.23 floor, standard library only, `net/netip`, `iter`.

**Spec:** `docs/superpowers/specs/2026-10-20-mrt-v0.2-design.md` (read it with this plan; CLAUDE.md is the operating contract).

## Global Constraints

- Branch `release-0.2.0`; commit on it, never on `main`. Pushing, PRs, merging and tagging wait for the user.
- `go.mod` stays `go 1.23` with no `require`; no package imports `net`; `net/netip` only.
- AS width comes from the record type, never from the bytes.
- Lossless `Raw` and `TestLossless` unchanged.
- Conventions C1–C3 hold (`go run ./internal/apisurface -check`); the one deliberate exception is `(*Interner).Decode` returning `*Path` (user's decision).
- `Routes(records)` yields exactly what it yields today, plus `Originated`; the only other visible change is the R20 amendment.
- A golden is oracle output, never hand-edited: `MRT_GOLDEN_UPDATE=1 go test -run TestMatches .`, then read `git diff testdata/golden`.
- Every figure in a doc or the CHANGELOG comes from a command run in this work, with its log under `.data/` named. memguard.sh is not installed here: heavy runs use `GOMEMLIMIT` and run alone.
- Before merge: `env GOMAXPROCS=4 FUZZTIME=15s scripts/check.sh` ends `check: ok`, and an independent reviewer reads the whole diff.

## Review Focus

1. One `Interner` used from several goroutines at once (collectors loaded in parallel): no data race, and every result equals a serial decode. Test in Task 7.
2. A caller who keeps a path and then lets the input buffer be reused or overwritten: a path from `Clone` or the interner is unchanged. Tests in Tasks 2 and 7.
3. The same attribute bytes under different `Context`s (TABLE_DUMP's 2-byte AS vs TABLE_DUMP_V2's 4-byte; RIB vs UPDATE): never the same shared path. Test in Task 7.
4. Two RIB entries for prefixes of different lengths whose full-form MP_REACH differ only in NLRI (and so in attribute length): one shared path. Test in Task 7.
5. An extended community of a type nobody knows (0x1A/0x70 seen in the wild): its 8 bytes survive and print raw, never mislabeled. Test in Task 5.

### Task 5: Typed extended communities

**Interfaces:**
